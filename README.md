# Pi Claude Minimal Subagents

A minimal Pi extension that lets Pi run the same Claude-native subagent definitions used by Claude Code.

## What it does

- Discovers shared agent definitions exposed through `.pi/agents/` and `.claude/agents/`.
- Maps supported Claude tool permissions and named skills into Pi.
- Supports optional Pi-only overrides for models, thinking, tools, skills, and extensions.
- Runs each subagent in a separate child Pi process while reporting compatibility warnings for unsupported Claude fields.
